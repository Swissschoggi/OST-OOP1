# Encryption
Braucht man wenn kein unbefugter lesen soll.

## Key Terms
Plaintext or cleartext
- Before a message is put into a coded form.
Ciphertext or cryptogram
- The sender of a message uses a cryptographic algorithm to encrypt the plaintext.
Cipher
- The encryption algorithm
Key or cryptovariable
- A key is nothing more than a number.
One-way functions
- A one-way function is a mathematical operation that easily produces output values for each possible combination of inputs but makes it impossible to retrieve the input values.
Reversability
- Reversabilty is a very important property in cryptography because we should be able to undo the operation of encryption
Nonce
- The nonce must be a unique number each time used
Initializing vector (IV)
- An IV is a random bit string

### Kerckhoffs's principal
Security-Through-Obscurity-Principle
- The security of a system or process depends on the confidentiality of its secrecy of its functioning
The security of an encryption method is based on the secrecy of the key and not on the secrecy of the encryption algorithm
