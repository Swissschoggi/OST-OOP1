## Social Engineering
Psychological manipulation to damage organization or perform a damaging action

- Phishing - Emails impersonating someone/something
- Spear Phishing - Targeted Phishing
- Vishing - Voice Phishing
- Smishing -  SMS Phishing


## Software Attacks & Malware
Attack involving software made to steal or damage data

- Virus - Attaches to programs and spreads
- Worms - Self replicating and spreads over network
- Trojan Horse - Disguised as legitimate software
- Ransomware - Encrypts data and wants payment
- Rootkits - Stealthy tools that hide malicious activity and maintain privileged access

## Denial of Service
Overwhelming a System with too many requests

- DoS - Single Source
- DDoS - multiple attackers
- Botnet - Multiple infected computers
- SY-Flood Attack - Sending many connection requests without completing them

## Web Application Attacks
Exploits vulnerabilities in web applications to steal data, manipulate content, or gain unauthorized access

- SQL injection - SQL commands that allow unauthorized access

## Password/Authentication Attacks
Bypassing Login systems

- Brute Force - Just try until it works

## Physical Threats
Threats or attacks that affect the physical infrastructure

- Theft
- Environmental Damage
