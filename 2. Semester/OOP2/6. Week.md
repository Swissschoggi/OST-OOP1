### Big O-notation
$f(n)$ ist $O(g(n))$ falls
reelle, positive Konstante ${\color{red}c}>0$, Ganzzahl-Konstante ${\color{magenta}n_0}\geq 1$, so dass
$$
f({\color{yellow}n})\leq {\color{red}c}g({\color{yellow}n})\text{ für }{\color{yellow}n} \geq {\color{magenta}n_0}
$$

| Name          | Klasse          | Beispiel                       |
| ------------- | --------------- | ------------------------------ |
| Konstant      | $1$             | Array Lesen                    |
| Logarithmisch | $log(n)$        | Binäre Suche                   |
| Linear        | $n$             | Lineare Suche                  |
| Log-Linear    | $n\cdot log(n)$ | Merge Sort, Quick Sort         |
| Quadratisch   | $n^2$           | Bubble Sort, Insertion Sort    |
| Kubisch       | $n^3$           | Gleichungssystem lösen         |

| Exponentiell  | $2^n$           | Berechnung aller Teilmengen    |
| Faktoriell    | $n!$            | Berechnung aller Permutationen |
Falls $f(n)$ Polynom vom Grad $d$ ist, ist $f(n)\in O(n^d)$ 
1. Alle tieferen Potenzen weglassen
2. Konstanten weglassen

public static void selectionSort(int[] arr) {
	int n = arr.length;
	for (int i = 0; i < n -1; i++) {
		int minimum = i;
		
		for (int j = i + 1; j < n; j++) {
			if (arr[j] < arr[minimum]) {
				minimum = j;
			}
		}
		swap(arr, i, minimum);
	}
}
