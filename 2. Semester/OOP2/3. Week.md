### Annotations
`@Override` -> überschreibt eine Methode der Superklasse
`@Test`
- Sind Metadaten: Daten über das Programm
- Kein Teil des eigentlichen Programmcodes

Annotation definieren:
```Java
package annotations;

import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

@Target(ElementType.TYPE) //Klasse
@Retention(RetentionPolicy.RUNTIME)
public @interface Author {
	String name();
	String date() default "N/A";
}
```
Erstellt Author annotation mit name und date
```Java
package annotations;

@Author(name = "John Doe", date = "2024-10-10")
public class AnnotationTest {
	// Code...
}
```
