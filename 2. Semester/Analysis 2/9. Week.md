$f(x)={d\over dx} F(x) \iff \int f(x) dx = F(x) + const$ 

## Integration
$F(x) + const = \int {d\over dx} F(x)dx$
${d \over dx} (F(x)+const) ={d \over dx} F(x) = f(x)\implies {d \over dx} \int f(x) dx = f(x)$

### Beispiel
$F(x)=x^n \implies F'(x)=nx^{n-1}$
$\int F'(x)dx=\int nx^{n-1}dx= F(x)+const=x^n+const$

Integralregel: ${\color{green}\int x^n dx{1\over n+1}}\int (n+1)x^n dx = x^{n+1}+const$

Ableitungsregel: ${d \over dx}(\alpha F(x)+\beta G(x))=\int \alpha F'(x)+\beta G'(x) dx$
wird zu folgendem mit der integralregel:
$\color{orange}\alpha F(x)+\beta G(x) + const = \int\alpha F'(x)+\beta G'(x) dx$
$\color{green}\alpha\int f(x)dx + \beta\int g(x)dx+const=\int \alpha f(x)+\beta g(x)dx$

Kettenregel:
$\int {d \over dx} F(g(x))dx=\int F'(g(x)) g'(x)dx$
$\color{orange} F(g(x)) + const =\int F'(g(x))g'(x)dx$
$\color{green} F(g(x)) + const = \int f(g(x))\cdot g'(x)dx$

Substitutionsregel:
$\int f(g(x)) \cdot g'(x)dx=(\int f(u)du) | u= g(x)$
- Integrand ist Produkt
- Ein Faktor ist verschachtelt $f(g(x))$
- Ableitung von $g(x)$ ergibt den zweiten Faktor

### Beispiel
$\int e^{sin(r)}cos(r)dr$
1. Prüfen ob $sin'(r)=cos(r)$
$\int e^{sin(r)}cos(r)dr=\int e^u du$
$\int e^{sin(r)}cos(r)dr=(\int e^u du)=(e^u+const)=e^{sin(r)}+const$


$\int sin(x^2+x)\cdot (2x+1)dx$
1. Prüfen ob Ableitung von $x^2+x=2x+1$
$\int sin(x^2+x)\cdot (2x+1)dx=(\int sin(u)du)=-cos(u)+const=-cos(x^2+x)+const$
