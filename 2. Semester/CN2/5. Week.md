## BGP
1. Highest Weight (cisco proprietary)
2. Highest locla preference
3. originate (next hop 0.0.0.0)
4. Shortest AS Path Length
5. Lowest origin code (IGP<Incomplete)
6. Lowest MED
7. eBGP path over iBGP path
8. shortest IGP path to BGP next-hop
9. Oldest path
10. lowest Router ID
11. lowest neighbor IP address

##### eBGP Loop protection
Every router adds its AS and sees if it sees a prefix that it itself has implemented and discards the packet
```BGP Table:
208.65.153.0/24
NHOP 14.0.0.2
AS_PATH 102 103
```
##### iBGP Loop protection
if information from eBGP comes in iBGP sends it from the receiving router to all the other routers in the AS. Full Mesh.
###### Router reflector
Each router in the AS is connected to the router reflector and sends information from other AS to the router deflector, which in turn distributes it. No Full Mesh.

#### Enterprise Internet Connectivity options
- Single homed -> one ISP one customer
	- No BGP
		- static default route on the customer side
	- Uses BGP
		- Changes in the customer topology will then be sent to the provider.
- multihomed -> two ISPs one customer
	- active/active design
	- 
- dual homed -> one ISP one customer but two connections
	- one or two customer routers
	- runs BGP
	- ISP announces default route
- dual multihomed -> two ISPs one customer but each has two connections
