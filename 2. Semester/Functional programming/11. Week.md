```Haskell
do { x <- getChar; putChar x}
```
`do` is just syntactic sugar
`x` is of type `Char`
`getChar` is of type `IO Char`
`putChar` is of type `Char -> IO()`

`getChar >>= (\x -> putChar x)`
`\x -> putChar x` is type `Char -> IO()`
`(>>=): IO a -> (a -> IO b -> IO b`

```Haskell
getLine :: IO String
getLine = do
	x <- getChar
	if x == '\n' then
		return []
	else
		do
			xs <- getLine
			return (x:xs)
```
