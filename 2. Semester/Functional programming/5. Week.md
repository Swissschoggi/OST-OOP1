## Higher order functions
Can accept functions as input and return functions as output

#### Map Function
takes a list and applies a function to every element of that list.
```Haskell
map (+1) [1, 3, 5, 7]
-- [2, 4, 6, 8]
```
#### Filter Function
Selects every element from a list that satisfies a predicate
```Haskell
filter even [1 .. 10]
-- [2,4,6,8,10]
```

#### Foldr Function
Many functions have a similar build:`sum, product, and`

```Haskell
fold v o [] = v
fold v o (x : xs) = x `o` (fold v o xs)
```
