#### Recipe Defining functions
1. Write down the *specification* of the function you want to define. -> plain text
2. Identify its *input* and *output types*.
3. Write down its *type signature*.
4. Write down some examples of what you expect the function to do (*test cases*), and some *properties* that you think the function should satisfy.
5. Write a* template/skeleton* of the function you want to define with appropriate names for its inputs.
6. *Complete* the *right hand sides* of your definition. Use only inputs and functions in scope.
7. Check that the i*nferred type agrees with the type you were aiming for*, that the test cases and properties are *satisfied*, and that the definitions are *valid properties* of the function being defined.

##### Pattern matching
Defining function by case distinction by the pattern of its input.
```Haskell
myNot :: Bool -> Bool
myNot False = True
myNot True = False

--- >>> myNot (myNot True)
--- True
```
