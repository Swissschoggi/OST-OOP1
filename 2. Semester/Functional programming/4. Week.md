### List comprehension
$\{x^2 | x\in [1...5]\}$  = `[x^2 | x <- [1..5]]` 

```Haskell
-- primes n is a list that contains all the prime numbers until n
primes :: Int -> [Int]
primes n = [x | x <- [2..n], isPrime x]

primes 10 == [2,3,5,7]

-- isPrime n is a True if n is a prime number
isPrime :: Int -> Bool
isPrime n = factors n == [1,n]

isPrime 13 == True
isPrime 10 == False

-- factors n is a list containing all the factors of n in increasing order
factors :: Int -> [Int]
factors n = [x | x <- [1..n], n `mod` x == 0]

factors 10
```

#### Making change
Repeating structure
```Haskell
change :: (Num a, Ord a) => a -> [a] -> [[a]]
-- Base case no return
change 0 _ = [[]]
-- Base case no coins to return
change _ [] = []
change n (c : cs)
-- if the amount is less than the current coin denomination, it cant be used
-- for every c in list cs check if it is less than the value n
	| n < c = change n cs
-- otherwise one can either use the coin or not use the coin
	| otherwise = map (c:) (change (n -c) (c : cs)) ++ change n cs
```
