# Declaring types and Classes
## Declaring Types
type declaration:
`type String = [Char]`
String is a list of characters

```Haskell
type Pos = (Int, Int)

--we can define:

origin :: Pos
origin = (0, 0)

left :: Pos -> Pos
left (x, y) = (x - 1, y)
```

cant be recursive:
`type Tree = (Int, [Tree])` won't work.

## Data declaration
`data Bool' = True' | False'`
declares a new type called  `Bool'` that can either be `True'` or `False'`

Data Types can have generic data types inside them and they can also be recursive.
`data List a = Nil | Cons a (List a)`
